Features

Transmutation

Convert between every format FFmpeg speaks. Pick an input, pick an output — the spell does the casting.

Compression

CRF-based quality control or target file size, with verified output on every pass.

Subtitles

Burn SRT, ASS and VTT into the frame, or mux them in as soft tracks that travel with the file.

Extraction

Pull audio and images from any media stream without touching what you don't ask for.

Timeline Forge

Trim, scale and rejoin over raw FFmpeg operations — every gesture compiles to a readable command.

Batch Queue

Enqueue entire shelves of files and walk away; parallel workers report every miss.
