GALDR

A desktop forge around FFmpeg. Convert, compress and cut video, audio and image files — the heat is in your hands.

v1.4.2 · windows / macos / linux · tauri + react + rust

Furnaces 01–06 ahead
01

Conversion Engine

Every codec FFmpeg ships is wired straight to the panel. Name your file, name its new form — the forge handles the rest.

mp4 · mkv · webm · avi · 60+ codecs
02

Compression Pass

Set the grain, watch the weight fall away. Constant quality or target size — every pass is verified before it commits.

crf 18–51 · target-size mode · pre-commit verify
03

Subtitle Burn-In

Inscriptions etched into the frame or bound softly so they travel with the file. SRT, ASS and VTT all accepted.

srt · ass · vtt · styled burn-in · soft subs preserved
04

Audio Extraction

Pull the voice from the moving image. Streams you don't touch are copied whole — nothing is re-encoded twice.

mp3 · flac · ogg · stream-copy safe
05

The Forge Timeline

Trim, scale and rejoin on a timeline built over raw FFmpeg operations. Every gesture compiles to a command you can read.

non-destructive · inspectable commands · undo-safe
06

Batch Queue

Enqueue a whole shelf of files and walk away. The forge runs while you're gone and reports every miss.

parallel workers · resume on failure · per-file log
